# Reguły UTM

Format:

`utm_source=<facebook|instagram|tiktok>`

`utm_medium=<paid_social|organic_social>`

`utm_campaign=2026-10_beds_<3f|twist>_<awareness|lead>`

`utm_content=<hypothesis>_<format>_<variant>`

Przykład:

`?utm_source=instagram&utm_medium=paid_social&utm_campaign=2026-10_beds_twist_lead&utm_content=chair_transform_reel_v1`

Nie używaj w UTM danych osoby, diagnozy, numeru telefonu ani innych informacji o zdrowiu.
