# Materiały produktowe

Przed generowaniem dodaj prawdziwe materiały w następującej strukturze:

```text
assets/products/
├── bed-3f/
│   ├── hero-front.jpg
│   ├── side.jpg
│   ├── pilot.jpg
│   ├── details.jpg
│   └── demo.mp4
└── bed-twist/
    ├── hero-front.jpg
    ├── side.jpg
    ├── pilot-1.jpg
    ├── pilot-2.jpg
    ├── details.jpg
    └── full-chair-sequence.mp4
```

Zdjęcia ze strony można wykorzystać, jeśli Siloe ma do nich prawa. Dla TWIST potrzebne jest rzeczywiste nagranie pełnego ruchu, ponieważ generator nie powinien odtwarzać mechaniki z wyobraźni.
